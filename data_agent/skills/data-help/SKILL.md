## Help

**Data Availability:**
- /data/data-availability/ — Browse data sources and check availability
- /data/map/ — Interactive map with raster tiles and admin boundaries

**Data Sources:**
- NASA POWER, ERA5, AgERA5 provide all 4 weather variables (tmax, tmin, rain, srad)
- CHIRPS provides high-resolution rainfall
- CHIRTS provides high-resolution temperature
- Combined datasets merge sources for complete high-resolution coverage
