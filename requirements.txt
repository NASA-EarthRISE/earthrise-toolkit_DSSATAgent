# =============================================================================
# Consolidated requirements for EarthRISEAgents
# Merged from ChatAgent, DataAgent, KnowledgeAgent, SimulationAgent
# =============================================================================
#
# This is the high-level dependency LIST (loose constraints). For REPRODUCIBLE
# builds, commit a fully pinned lock and install with `pip install -r <lock>`.
# The fast-moving langchain / langgraph stack in particular can break across
# minor releases, so a lock is strongly recommended before publishing.
#
# ARCHITECTURE MATTERS — the lock is platform-specific:
#   * requirements.arm64.lock  — DEV freeze on linux/arm64 (Apple Silicon,
#       Dockerfile.dev). Convenience only; NOT for production.
#         docker compose exec web pip freeze > requirements.arm64.lock
#   * requirements.lock        — CANONICAL production lock, generated on
#       linux/amd64 (prod Dockerfile pins --platform=linux/amd64). Produce it
#       from the amd64 prod build (run scripts/build_venv.sh in the amd64
#       image, then `pip freeze`). An arm64 freeze is not guaranteed to
#       reproduce on amd64 for the binary stack.
# =============================================================================
